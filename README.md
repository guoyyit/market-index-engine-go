# market-index-engine-go

本地运行的证券市场指数计算与成分管理服务。无外部数据源依赖，全部证券、行情、
调样单与公司行为均由本地调用方录入；服务同时维护**价格指数**与**全收益指数**
两种口径，保证成分调整与公司行为前后指数值连续，并支持任意历史时点的精确重建。

## 快速开始

```bash
go build ./...
go test ./...          # 单元与集成测试
go test -race ./...    # 并发竞态检测
go run ./cmd/demo      # 端到端示例（含重启与历史重建）
```

## 1. 基期除数法

对每一条口径（价格、全收益）独立维护：

- 每个成分的“指数持有股数” `q_i`；
- 一个统一除数 `D`。

指数点位定义为

```
Index = Σ(q_i × P_i) / D
```

基期初始化时，对归一权重 `w_i` 取 `q_i = w_i / P_i^0`，使 `Σ q_i × P_i^0 = 1`，
并令 `D = 1 / 1000`，基期点位恰为 1000（`DefaultBaseLevel`）。

价格日常波动时除数与股数均不变，点位随市值自然变化。

## 2. 成分/权重变更的除数调整

成分调样（纳入、剔除、改权）在生效日原子切换。新权重 `w'_i` 先经封顶处理并
归一，再按当前价格重设股数 `q'_i = w'_i / P_i`，同时把除数修正为

```
D' = D × (Σ q'_i × P_i) / (Σ q_i × P_i)
```

切换瞬间新旧组合市值的非交易差异被除数吸收，点位严格相等，不产生跳变。
切换在一把全局锁内整体完成，任何查询都不会读到“新旧成分混合”的中间状态；
当生效日新纳入成分的价格尚未到齐时，切换等待其到齐后再原子完成。

## 3. 双口径与公司行为规则

两种口径持有各自独立的股数与除数。每次公司行为通过“股数系数”表达
（股数按系数放大等价于除数反向修正）。

| 公司行为 | 价格指数系数 | 全收益指数系数 | 说明 |
|---|---|---|---|
| 现金分红（每股 d，除息前价 p） | `1`（不修正，自然回落） | `p / (p − d)` | 现金按除息参考价再投资，点位不回落 |
| 送转/拆股（1 拆 k） | `k` | `k` | 股数增加、价格等比下降，两口径天然连续 |
| 配股（认购比 r、认购价 s） | `p / TERP` | `p / TERP` | `TERP = (p + r·s)/(1 + r)`，除权后点位连续 |

由此：

- **两口径可相互换算**：`TotalReturn / Price` 即累计再投资系数
  （`Engine.ReinvestmentFactor()`）；
- 该系数**只**由现金分红的再投资累积——送转与配股对两条口径影响完全相同，
  不产生口径差异。

公司行为带公告日与除权除息日：公告日仅登记，除息日随行情结算；除息前收盘价
在结算时快照并随事件持久化（`CorporateAction.CumPrice`），保证重建可复现。

## 4. 个股权重上限（封顶）

给定上限 `c`（如 0.10），求解统一系数 `f ≥ 1`，使

```
p_i = min(f × w_i, c),    Σ p_i = 1
```

`g(f) = Σ min(f·w_i, c)` 对 `f` 单调不减，采用倍增找界 + 二分法求解，
必然收敛；触顶成分恰为 `c`，未触顶成分按同一 `f` 等比放大（相对权重不变），
最后对二分残差做整体等比修正，使总和在浮点意义下严格归一。上限低于 `1/N`
时返回 `ErrCapInfeasible`。封顶在基期初始化与每次调样时统一施加。

## 5. 历史重建与快照

所有输入均追加写入本地事件日志（`events.log`，JSON Lines，逐条 fsync），
事件类型包括：证券登记、基期、行情、公告（待生效调样/公司行为）、已应用的
公司行为与调样。事件按 `(时间, 序号)` 唯一确定顺序。

- `RebuildAt(t)` 重放“不晚于 `t` 的最后一个行情时点”之前的全部事件，
  与实时计算共用同一条确定性应用路径，因此逐点结果与实时值一致；
- `RebuildRange(from, to)` 一次顺序重放输出区间内每个行情时点的收盘值；
- 快照（`snapshot.json`，临时文件 + 原子重命名）只用于跳过日志前缀、
  加速恢复/重建，不改变结果。无快照时全量重放结果相同。

## 6. 并发与持久化

- 所有读写由 `sync.RWMutex` 保护；行情写入时“公司行为 → 价格更新 → 调样切换”
  在同一把写锁内完成，查询永远只观察完整一致的状态（已通过 `-race` 测试）。
- 行情必须按时间单调推进，迟到的旧行情返回 `ErrOutOfOrderQuote`。
- 同一业务 ID 的调样单/公司行为只接受一次，重启后也不会重复应用
  （`ErrEventExists`）。
- 重启时“快照 + 其后事件重放”恢复：已生效的除数调整、已登记的未来事件
  均不丢失。

## 主要 API

```go
engine, _ := index.OpenEngine("./data")       // 打开/恢复（NewEngine 为纯内存）
engine.RegisterInstrument(index.Instrument{Symbol: "AAA"})
engine.Initialize(weights, baseQuotes)        // 基期 1000
engine.SubmitChange(change)                   // 带公告日/生效日的调样
engine.RecordAction(action)                   // 分红/送转/配股
engine.ApplyQuote(quote)                      // 推送本地行情，原子结算
level := engine.Level()                       // 当前双口径点位与除数
factor := engine.ReinvestmentFactor()         // 全收益/价格换算系数
w := engine.Constituents()                    // 当前封顶后权重
v, _ := engine.RebuildAt(t)                   // 历史任意时点精确重建
vs, _ := engine.RebuildRange(from, to)        // 历史区间
engine.Checkpoint()                           // 可选快照优化
```

## 代码结构

| 文件 | 职责 |
|---|---|
| `types.go` | 领域类型：证券、权重、调样、公司行为、行情、指数值 |
| `divisor.go` | 除数法核心：股数/除数状态、基期初始化、调样除数修正 |
| `actions.go` | 分红/送转/配股的股数系数（纯函数） |
| `cap.go` | 权重封顶的缩放系数二分求解（纯函数） |
| `engine.go` | 并发安全的实时引擎、事件应用、快照转换 |
| `store.go` | 追加式事件日志与原子快照 |
| `history.go` | 任意时点/区间的确定性历史重建 |
| `cmd/demo` | 端到端可运行示例 |
