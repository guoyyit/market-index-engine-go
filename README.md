# market-index-engine-go

本地可运行的证券市场指数计算与成分管理服务（Go）。全部输入（成分、权重、
公司行为、行情）由本地调用方提供，不依赖任何外部数据源。

- 基期除数法（base divisor）计算指数，成分/权重变更通过调整除数保持数值连续；
- 同时维护**价格指数**与**全收益指数**两种口径，二者只差已计入的分红再投资；
- 支持带公告日/生效日的成分调样，生效日前按旧篮子、生效日原子切换；
- 支持单成分权重上限，通过调整系数迭代封顶，封顶后权重归一、指数连续；
- 任意历史时点可精确重建，重建与实时结果逐点一致；
- 事件日志 + 快照持久化，并发安全，重启后已生效调整不丢失、不重复。

## 快速开始

```go
e, _ := index.NewEngine("./data")
defer e.Close()

e.RegisterIndex(index.IndexDef{
    Code: "IDX", Name: "Demo", BaseDate: base, BaseValue: 1000,
}, []index.Constituent{
    {Symbol: "AAA", Weight: 0.6},
    {Symbol: "BBB", Weight: 0.4},
}, map[string]float64{"AAA": 10, "BBB": 20})

e.AnnounceRebalance("IDX", index.Rebalance{ID: "RB1",
    AnnounceDate: d1, EffectiveDate: d5, Constituents: ...})
e.RecordCorporateAction("IDX", index.CorporateAction{
    ID: "DIV1", Symbol: "AAA", Type: index.ActionCashDividend,
    ExDate: d2, CashPerShare: 1})

e.OnTick("IDX", d2, map[string]float64{"AAA": 9, "BBB": 20})
p, _ := e.PriceIndex("IDX")
tr, _ := e.TotalReturnIndex("IDX")

points, _ := e.Rebuild("IDX")         // 全历史逐点重建
at, _ := e.RebuildAt("IDX", someTime) // 任意时点
```

运行内置示例：`go run ./cmd/demo`；测试：`go test ./... -race`。

## 除数法

记成分权重（等价于固定份额口径）为 w_i，行情为 P_i，除数为 D：

```
价格指数 = Σ w_i · P_i / D
```

基期篮子与基期价格确定基期原始市值 S0，除数被固定为

```
D0 = S0 / 基期点数（默认 1000）
```

任何结构性变更（成分/权重调整、送转、配股）发生的瞬间，记变更前原始和为
S_old、变更后在**同一组价格**下的原始和为 S_new，则令

```
D_new = D_old · S_new / S_old
```

于是变更前后指数值严格相等，变更不会造成跳点；之后只有真实行情变动进入指数。

## 价格指数与全收益指数

全收益指数在价格指数之外，累计把现金分红按除权日价格再投资：

```
全收益指数 = 价格指数 · TRFactor
TRFactor = Π_j (P_ex,j + D_j) / P_ex,j
```

- **现金分红**：价格指数的权重/除数**不调整**，指数随自然除权回落（与
  沪深 300 等价格指数口径一致）；全收益指数按上式把分红再投，TRFactor 增大。
- 因此两种口径可相互换算，且其差异**只能**来自累计分红再投资：
  `TR / Price = TRFactor`。
- 送转、配股属于结构性变化，两种口径都调整除数，TRFactor 不变。

## 公司行为调整规则

设旧价（上一笔行情的含权价）P_cum，除权日观察价 P_ex：

| 行为 | 参数 | 份额/权重变化 | 理论除权参考价 | 除数调整 |
|---|---|---|---|---|
| 现金分红 | 每股 D | 不变 | — | 不调整（仅 TRFactor 计再投） |
| 送转/拆股 | 每旧股 k 股 | w ← w·k | P_ref = P_cum / k | D 按新旧原始和比例调整 |
| 配股 | 每旧股 r 股、配售价 Ps | w ← w·(1+r) | P_ref = (P_cum + r·Ps)/(1+r) | 同上 |

除数调整锚定理论除权价，仅把结构变化吸收进除数；观察价相对理论价的偏离
（真实涨跌）照常进入指数。送转/配股按先公司行为、后成分调样的固定顺序在
同一笔 tick 内原子生效。

## 成分调样

`AnnounceRebalance` 记录（公告日, 生效日, 目标权重）。生效日之前：

- 查询返回旧成分与旧权重；
- 行情仍按旧篮子计算；
- 待生效调样保存在调度队列中，查询不可见。

首个 `t >= EffectiveDate` 的 tick 上，所有到期调样（按生效日、ID 排序）
一次性切换：目标权重先归一/封顶，再用同组价格令
`D_new = D_old · S_new/S_old`。整个切换在写锁内完成，任何查询都不会读到
新旧成分混合的中间状态。

## 权重上限（调整系数）

每个成分的调整系数 a_i 使其有效权重为 w_i·a_i 归一后不超过上限 c：

1. 超上限的成分被“钉”在 c，释放的权重按其余成分原权重比例分配；
2. 每轮重新分配后可能有新的成分触及上限，继续钉住并迭代；
3. 迭代单调收敛（容差 `1e-12`，上限 10000 次），最后统一归一，
   权重总和严格为 1。

下限保护：上限低于 1/N 时数学上不可行（N 个成分总和最多为 N·c<1），
此时有效上限取 1/N。基期注册与每次调样都走同一封顶路径，配合除数调整，
封顶本身不造成指数跳变。

## 历史重建

所有输入（注册、调样公告、公司行为、tick）以事件形式写入仅追加日志。
实时计算与历史重建共用同一个确定性状态转移函数 `applyEvent`：

- `Rebuild(code)` 从**完整事件日志**重放（不依赖快照），返回每个 tick 的
  价格/全收益点位；
- `RebuildAt(code, t)` 返回不晚于 t 的最后一个 tick 的状态；
- `RebuildRange(code, start, end)` 支持任意闭区间。

同一输入下重建结果与实时值逐点相等（测试中按 `1e-12` 校验）。快照只减少
重启/重建的工作量，不参与重放计算，因此不会改变结果。

## 持久化与并发

- 存储目录下 `events.log` 为每行一个 JSON 的追加日志（写入即 `fsync`，
  先持久化后生效），`snapshot.json` 为周期性快照（临时文件 + rename 原子发布）。
- 重启时加载快照后重放其后的全部事件；已生效动作带 `applied` 标记，
  不会被重复应用，待生效调样继续保留在队列中。
- 变更操作串行化（写锁），查询使用读锁；一次 tick 内的多个行为/调样
  原子完成，读者永远看不到部分更新。
